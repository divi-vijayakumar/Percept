# percept-vision

The Python SDK for Percept, a decision layer for live video: it watches a stream for
plain-language conditions and tells your agent, once per occurrence, when one becomes true. See
the [repository README](https://github.com/divi-vijayakumar/Percept#readme) and its
[documentation](https://github.com/divi-vijayakumar/Percept/tree/main/docs).

Status: pre-release (`1.0.0.dev1`). The 1.0 API may still change before 1.0.0. The last
published release, 0.7.0, is a research preview with a different API.
