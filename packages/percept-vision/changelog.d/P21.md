### Added — deterministic video-interest intervals

Finite tier-0 replay traces can now turn a caller-selected scalar admission signal into typed
`interest.entered` / `interest.updated` / `interest.exited` intervals with stable
replay-deterministic ids. Events carry distinct source and observer bounds, an explicit caller-owned
stream epoch, evidence id, reason, score, optional calibrated confidence, coverage, region/track
metadata when supplied, and the admission/detector identities.

`InterestIntervalEngine` makes hysteresis, consecutive-sample debounce and idle expiry explicit.
Reconnect, Watch expiry and end-of-stream close an interval with distinct reasons; a silence gap at
the expiry boundary splits rather than silently forward-filling. Invalid/out-of-order evidence is
rejected before state changes, and the lifecycle cannot emit an orphan update/exit or duplicate enter.

`Tier0MotionInterest` is a replay-only view over a tier-0 `GateDecision`, wired into the
finite-iterable `GatedWatchLoop`/`LoopReport` harness, not `percept.run`. It scores each interval
from the per-Watch `WatchAdmissionOutcome` — the statistic that actually admitted, whether that is
the whole-frame mean, `block_max`, `p95`, an ego residual or a structural/semantic channel — and
labels it with that outcome's admission/detector identity. `GatedWatchLoop` requests those outcomes
(`include_outcomes=True`) exactly when an interest adapter is wired, so a run with no interest
recorder does not pay per-Watch outcome construction on every frame, and a localized-salience Watch
replays as a real timeline rather than an empty one. That projection is the single function
`interest_admission_from_outcome`, shared with the live `LiveInterestTracker` recorder, so an offline
replay and a live run cannot describe the same admitted unit differently. A hand-built decision
carrying no outcomes still falls back to the reported whole-frame mean gauge under the adapter's own
constructor identity. Engines are keyed by admitting statistic
rather than by Watch, because the emitted event has no `watch_id` to attribute one to; the per-Watch
record is the live one. Every successful run supplies an explicit epoch plus independent observer
timestamps and closes at EOS; failures discard the unreturned epoch without manufacturing an orphan
exit, and the adapter is ready for the next chunk. Each epoch cold-starts and ends with a reset
tier-0 predecessor, so a frame from another epoch cannot manufacture motion; motion evidence ids hash
the exact ordered `previous,current` frame pair rather than the current frame alone. It still never
treats `decision.escalate` as semantic truth — that boolean names no Watch and no statistic. Motion
confidence remains explicitly unset, and callers must provide thresholds calibrated for their signal;
no universal quality bar is embedded.
