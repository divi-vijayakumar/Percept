### Added — episode-owned idempotency; the gate bit is no longer accidental per-episode memory

The gate is one bit **per key**, but *"have I already reported THIS episode?"* is a property of the
**episode**. Conflating the two was fragile: in an A→B→A trace, if B is a new episode that re-arms the
shared gate key and then fails its dwell (or is judged `ASK`) and never fires, A's unchanged revisit
rides the wrongly-armed edge and fires a **second time**. The same coupling let a memory-bound event —
a gate-key TTL eviction while the episode is still open — leak into user-visible behaviour.

`percept.behavior` now folds each observation against its episode's emission history **before** the
gate is consulted:

* **`EpisodeFoldResult`** — `{episode_id, match, mutation, should_rearm, should_evaluate_gate,
  supersedes}` over the closed `EPISODE_MATCHES` (`new` · `continuation` · `unbound` · `ambiguous`)
  and `EPISODE_MUTATIONS` (`confirmed` · `updated` · `retracted` · `closed` · `none`) vocabularies.
* **`episode_fold(decision, *, emitted, mutation, ambiguous)`** — the pure, side-effect-free rule
  (the implementation recomputes it in shadow): a new episode with no emitted incident may keep evaluating and
  re-arms its own edge; once a revision has emitted, an **unchanged confirmation does not re-enter the
  gate** (`should_evaluate_gate=False`); a semantically-accepted **update** creates a new revision and
  MAY re-arm, naming the revision it `supersedes`.
* **`EpisodeIncidentLedger`** — the episode-owned, non-evictable record of how many incidents each
  episode has emitted (keyed by the globally-unique episode id, so it never collides across subjects
  that share a gate key and a TTL sweep cannot erase it).
* **`BehaviorExecutor.fold_episode(...)`** reads the ledger into a fold; **`fire_judged(..., fold=)`**
  honours it (idempotent suppression is metered `…​.idempotent_suppressed`, never silent). Recording an
  emitted incident happens only when one is actually delivered — an escalated `ASK` counts, a withheld
  fire does not.

**Invariant (declared and pinned by tests):** if the gate key's TTL expires while the episode is still
open, an unchanged episode **must not** refire merely because gate memory disappeared. Idempotency
lives on the episode, not on the evictable gate bit.

### Changed

* **`percept/gate.py` is mechanically unchanged.** The episode reaches the gate only as the existing
  `rearm()` / `evaluate()` calls; it stays one bit per key.

Defaults are unchanged and the work is additive: `fire_judged` with no `fold=` is **byte-for-byte** the
pre-Y3 gate-only path. The acceptance spec is the `eval/synthetic/continuation/` and
`eval/synthetic/idempotency/` fixtures (`tests/test_y3_episode_idempotency.py` encodes their assertions
so they hold in a worktree that does not carry the gitignored fixture trees).
