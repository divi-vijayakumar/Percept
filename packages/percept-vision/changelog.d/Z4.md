### Added — evidence dereference: the missing third webhook option (ADR-003)

Before evidence dereference, a webhook payload was all-or-nothing: `include_media=False` left the consumer with
**no** way to reach the evidence a fire was gated on, and `include_media=True` inlined base64 media
into the POST — an exfiltration vector for a client watching an accounting screen. ADR-003's
dereferenceable **handle** is the missing third option, and nothing in the ADR was built. This card
builds it, as a new additive module — `percept/watch.py` and `WATCH_VERSION` are untouched.

- **`percept.evidence.EvidenceArtifact`** — the opaque handle's resolved metadata head (ADR-003 §2):
  `ref`, `kind` (`"frame"`/`"crop"`/`"clip"`/`"bundle"`), `media_type`, `capture_start_ts`/
  `capture_end_ts` (same monotonic production domain as `JudgmentTiming`), `sha256`, `expires_at`. It
  carries **no bytes** — the pixels live in the store keyed by `ref`. It reuses `LabelRecord`'s exact
  egress construction: `to_egress()` is built from an `EGRESS_FIELDS` whitelist that structurally
  excludes `ref`, so the handle is un-emittable by default; a sink may opt in to the *bare handle
  string* via `to_egress(include_ref=True)`, never the bytes.
- **`percept.evidence.resolve_evidence(handle, *, store)`** — the only sanctioned path from a handle
  to its artifact (§2). It accepts a bare `ref` string or the existing **`EvidenceHandle`** (reused, not
  forked — resolve is built *over* that shape), and never returns a silent `None`.
- **Four typed failures** (§3): `EvidenceExpired` (retention closed / evicted), `EvidenceUnavailable`
  (not yet written / redacted / store hiccup), `EvidenceAccessDenied`, `EvidenceCorrupt` (sha256
  mismatch — the tamper-evidence signal). A resolution failure is never confusable with "there
  genuinely was no evidence."
- **`percept.evidence.EvidenceStore`** — the `ref → (metadata + local bytes)` index with the
  retention mechanism behind the resolver. Bytes are read by the distinct **local** `open_bytes()`
  (media is opt-in and off the wire); `redact()` clears bytes in place while keeping the metadata head
  (the `IncidentSnippet` privacy precedent) and can fire ahead of TTL; `reconcile()` sweeps expiry
  (the crash-recovery seam); `snapshot()` serialises the index (persistence-across-restarts seam).
- **A retention seam with no policy numbers baked in** (§5). Every number — TTLs, the global byte
  ceiling, per-class sub-budgets, the labelled-retention ceiling — is a caller-supplied
  `RetentionPolicy` field, defaulting to "no constraint" (no tune-to-green; ADR-003 §5's seven owner
  decisions stay open). The one thing fixed regardless of the numbers is `EVICTION_ORDER`
  (`silent_debug → sampled_debug → ask → fire`): byte pressure evicts **FIRE last**, and per-class
  sub-budgets stop a debug-capture storm from starving FIRE of its share.
- All names are additively re-exported from the `percept` package. `tests/test_evidence.py` (28
  cases) pins the guarantees: opaque-handle egress exclusion, the four typed failures, media-is-local,
  bundle child-namespacing, and FIRE-evicted-last under byte pressure.
