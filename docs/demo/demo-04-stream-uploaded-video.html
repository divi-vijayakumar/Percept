Advanced settings
A stative condition ("a person is visible") is decidable from one still frame. A dynamic one ("turns right", "stops", "sits down") is a statement about CHANGE — a still photo of a car in an intersection looks the same whether it is parked or doing 40, so single-frame evidence cannot contain the answer. Pick dynamic and raise fps.
A live source has no container to demux, so audio (fused) is ignored there and the run says so.
